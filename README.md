# NE Insights website

Static, multi-page Northeast India travel website for **NE Insights Tours and Travels** (<https://neinsights.in>), with one Netlify Function that delivers enquiry forms to the business mailbox.

- **Framework:** none. A small Node.js static-site generator (`scripts/build.mjs`) renders plain HTML, CSS and vanilla JavaScript into `dist/`.
- **Hosting:** Netlify, auto-deployed from GitHub (`pv-webservices/ne-insights`, branch `main`).
- **DNS:** GoDaddy (`ns65/ns66.domaincontrol.com`). **Email:** Zoho Mail, India data centre (`mx.zoho.in`), with SPF (`include:zoho.in`), DKIM (`zmail._domainkey`) and DMARC (`p=quarantine`) in place.
- **Enquiries:** `POST /api/enquiry` (Netlify Function) → Zoho SMTP (`smtp.zoho.in:465`) → `operations@neinsights.in`. No third-party form service.
- **Traveller feedback:** the homepage "Share your experience" form uses the same function (`form_type=feedback`) and mailbox. Nothing is published automatically. Approved testimonials are added by hand to `src/data/testimonials.mjs` (see `docs/CONTENT_UPDATES.md`). There is no testimonial database.

## Commands

Requires Node.js 22.18 or newer (`.nvmrc`). Run `npm install` once.

| Command | What it does |
| --- | --- |
| `npm run dev` | Preview build (noindex) served at <http://localhost:4321>. Forms use the real function code; emails are written to `output/mail/*.eml`, **never sent**. |
| `npm run preview` | Same, but with the production (indexable) build. |
| `npm run build` | Build `dist/` (production markup on Netlify's production context, noindex everywhere else). |
| `npm run build:production` | Force a production build locally. |
| `npm run typecheck` | TypeScript check of the function, the shared validation rules and the tests. |
| `npm run test:unit` | Unit tests for the enquiry handler with a mocked mail transport (Node's built-in test runner). |
| `npm run audit:seo` | Production build + technical SEO audit of every page (titles, descriptions, headings, canonicals, robots, Open Graph, JSON-LD, images, internal links, sitemap). Fails on any issue. |
| `npm run test:e2e` | Playwright browser tests: forms (endpoint intercepted), no-JS form, every page loads cleanly, 404, redirects, layout at 320–1440px, tap targets, keyboard, reduced motion, axe WCAG 2.1 AA on every page. First run: `npx playwright install chromium`. |
| `npm test` | All of the above in order. |
| `npm run images` | Regenerate the responsive AVIF/WebP images and 1200×630 social images from `source-files/images/`. |
| `npm run favicons` | Regenerate the favicon set from the logo master. |
| `npm run verify:live` | After a deploy: checks the live site (version, 404, redirects, headers, sitemap, favicons, form endpoint). It never sends an email. |

## Enquiry form setup (one time)

The function sends through the business's own Zoho mailbox, so messages pass SPF, DKIM and DMARC and land in the inbox. Each email comes from `"Visitor Name via NE Insights" <operations@neinsights.in>`, with **Reply-To** set to the visitor's email address. The subject is "New enquiry from {Name}: {topic}".

1. **Create a Zoho app password**: sign in to Zoho Mail as `operations@neinsights.in` → **My Account → Security → App passwords → Generate**. Name it "Website". Use it as `SMTP_PASS`, not the normal login password.
2. **Add environment variables in Netlify**: **Site configuration → Environment variables → Add a variable**, once per variable:

   | Key | Value | Settings |
   | --- | --- | --- |
   | `SMTP_HOST` | `smtp.zoho.in` | All scopes, all contexts |
   | `SMTP_PORT` | `465` | All scopes, all contexts |
   | `SMTP_USER` | `operations@neinsights.in` | All scopes, all contexts |
   | `SMTP_PASS` | the Zoho app password | **Contains secret values** ✓, scopes include **Functions**, deploy context **Production** only |
   | `MAIL_TO` | `operations@neinsights.in` | All scopes, all contexts |
   | `MAIL_FROM` | `operations@neinsights.in` | All scopes, all contexts |

   Optional: `ALLOWED_ORIGINS` (extra comma-separated origins), `SITE_URL` (defaults to `https://neinsights.in`).
3. **Redeploy**: **Deploys → Trigger deploy → Deploy site**. Functions only see new variables after a redeploy.
4. Send **one** real test from <https://neinsights.in/contact/> and confirm it arrives in the Zoho inbox (not spam) and that Reply answers the visitor.

`.env.example` lists the same variables. Never commit real values (`.env` files are git-ignored).

**Protection:** hidden honeypot field and a 3-second minimum fill time (both silently accepted and discarded); allowed origins (`neinsights.in`, `www`, Netlify previews, localhost); 5 submissions per IP per 10 minutes (function memory) plus Netlify's platform rate limit; server-side validation of every field including consent; header-injection-safe headers; HTML-escaped email body; suspicious content gets a "[Possible spam]" subject prefix instead of being dropped.

**Without JavaScript** the form is a normal POST, and the function answers with a 303 redirect to `/thank-you/`. With JavaScript, it validates inline, sends JSON in the background (20-second timeout) and shows offline, timeout and delivery-failure messages with phone, WhatsApp and email alternatives. The visitor's entries are never cleared on error.

## Deploying

1. Commit and push to `main`. Netlify runs `npm run build && npm run audit:built && npm run test:unit`. If the audit or tests fail, the deploy stops and the previous version stays live.
2. Deploy previews (pull requests) are built noindex automatically.
3. After a production deploy, run `npm run audit:seo && npm run verify:live`.

Redirects are generated into `dist/_redirects`: `www`/`http` → `https://neinsights.in`, `/x/index.html` → `/x/`, `/sitemap.xml` → `/sitemap-index.xml`, and retired package URLs. Netlify itself forces HTTPS and adds trailing slashes. The custom 404 page is `dist/404.html`, which Netlify serves with a real 404 status.

## Search engines

- Indexable pages carry `index, follow, max-image-preview:large`, a self-referencing canonical, Open Graph/Twitter tags and JSON-LD.
- `/thank-you/`, `/image-credits/`, `/sitemap/` (HTML sitemap) and the 404 page are `noindex, follow`, have no canonical and are not in the XML sitemap.
- Submit `https://neinsights.in/sitemap-index.xml` in Google Search Console. See `docs/GOOGLE-SEARCH-CONSOLE.md`.
